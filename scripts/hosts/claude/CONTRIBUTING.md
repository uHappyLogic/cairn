# Contributing to Cairn for Claude Code

This repository is the Claude Code distribution of [Cairn](https://github.com/uHappyLogic/cairn), and it takes no contributions directly. Every file on `main` is rendered from the sources of [uHappyLogic/cairn](https://github.com/uHappyLogic/cairn) by its host build and published verbatim by each Cairn release, so a change made here — a pull request against this repository included — would be overwritten by the next release. Issues, Discussions, projects, and the wiki are disabled in this repository on purpose.

Everything goes to the root repository instead:

- **Bug reports and feature requests** — open an [issue at uHappyLogic/cairn](https://github.com/uHappyLogic/cairn/issues/new/choose), using its bug or feature form.
- **Changes and pull requests** — read the root repository's [contributing guide](https://github.com/uHappyLogic/cairn/blob/main/CONTRIBUTING.md), which describes how a change is proposed, run as a milestone in a fork of the root repository, and submitted as a pull request there. The plugin's sources live under `core/` in that repository; this tree is a build of them.
- **Security vulnerabilities** — report them privately through the root repository's [Report a vulnerability](https://github.com/uHappyLogic/cairn/security/advisories/new) form, never as an issue or a pull request; its [security policy](https://github.com/uHappyLogic/cairn/blob/main/SECURITY.md) has the details.
- **Questions** — ask in the root repository's [Discussions](https://github.com/uHappyLogic/cairn/discussions/new?category=q-a).
