# Milestone 28: Ways of using Cairn

## Goal

Promote the untracked `temp/CAIRN_USAGE.md` into a tracked `docs/ways-of-using-cairn.md`: a single extensible page of goal-oriented command-chain snippets (for example starting a milestone, a mixed-agent requirements review, putting more intelligence into a stuck milestone, executing tasks), each under one fixed per-way template (a `##` heading naming the goal, one or two sentences on when to use it and what it yields, then the chain as a fenced block). The chains are generalized for any reader: private aliases, local paths, and project-specific milestone ids become placeholders or documented equivalents, and the headless flags (`--dangerously-skip-permissions`, `--model`, `--effort`, `--add-dir`) are kept with one sentence explaining what each means. The page presents mixing along every available axis, hosts (Claude Code and Antigravity on one repository), models, and effort levels, as mechanics the reader can combine, without asserting benefit claims that belong to `docs/design-claims.md`. The README's "How it works" section links to it beside the existing docs links; `CONTRIBUTING.md` is not modified, and the page's template is what lets a later contribution (such as an ultracode-driven multi-milestone way) be added as one more section.
