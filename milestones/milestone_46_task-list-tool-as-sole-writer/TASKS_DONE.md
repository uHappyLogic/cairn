# TASKS DONE

## Add Task-List Tool With Initialize And Insert

Add `core/tools/task_list.py`, a self-contained stdlib-only Python 3.9+ tool (its own stdin reader, `ToolError`, one-`Error:`-line main with its describe/fail path, and same-directory atomic writer keeping the target's mode; importing neither sibling tool and leaving them and the build untouched; touching no git) that holds the whole-file model and canonical render every write of a milestone's `TASKS_TODO.md` and `TASKS_DONE.md` shares — the fixed heading rendered over whatever preamble stands before the first `##` section, sections ending at their `---` when one comes first and otherwise at the next column-0 `## ` heading or the end of the file, a `---` read as a separator only when the next non-blank line is such a heading or the end of the file, the canonical blank-line layout ending in `---` plus one newline, and titles matched only by exact whitespace-folded, case-folded equality — and its two `TASKS_TODO.md` writers as the `## Decisions` fix them: `initialize <MILESTONE_DIR>`, reading the whole ordered list on standard input in the file's own `##` heading / body / `---` form, validating every section, and replacing the file with the heading and the list in one atomic write or leaving it byte-for-byte unchanged, with no flag; and `insert <MILESTONE_DIR> "<Task Title>"`, reading only the body on standard input, composing the heading, body, and `---` itself, and taking exactly one of `--end`, `--before <Task Title>`, or `--after <Task Title>` in a required mutually exclusive group (no flag is argparse's exit 2), both refusing with one `Error:` line and the file unchanged an empty title or body, a folded title the file already holds, or an anchor naming no section, and checking no other rule of `task-format.md`. Verified by running both subcommands by hand against a sandbox milestone (blank-line drift and a damaged heading normalized on the first write, a body `---` or `## ` line written verbatim by `insert` and surviving the next re-parse, every refusal leaving the bytes unchanged, `--help` and the exit statuses matching the shared contract), by the existing suite passing under `uv run pytest` and `uv run --no-project --python 3.9 --with pytest pytest`, and by `uv run scripts/build_hosts.py` rebuilding the three host trees so `uv run scripts/build_hosts.py --check` passes with the tool copied byte-identical into each.
